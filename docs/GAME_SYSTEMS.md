# GAME SYSTEMS

## Core identity
- top-down / isometric zombie roguelite-survival
- in-world LitRPG Interface
- superhuman abilities
- systemic urban exploration
- extraction-style risk/reward excursions
- persistent safehouses and districts

## Co-op
Architecture targets **2–4 players**. The first vertical slice may expose only 2-player functionality.

## Survival
- Health
- Stamina
- Hunger
- Cold
- Infection
- Injuries
- Stress / Panic

## Character systems
Separate:
- physical attributes
- cognitive attributes
- psychological attributes
- traits
- habits
- dynamic conditions
- learned skills
- supernatural abilities
- foreign fragments

## Progression
Skills improve by use. Knowledge sources may accelerate learning. Repetitive exploit-like actions should have diminishing XP.

## Crafting
Loop: **find -> dismantle -> combine -> repair -> improve**.

## Fortification
Temporary shelter -> camp -> fortified safehouse.

Stronger bases create more light, noise and stored value, increasing the chance of attracting threats.
